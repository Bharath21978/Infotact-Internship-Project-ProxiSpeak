# ProxiSpeak MID Review Demo and QA Guide

## Project Overview
ProxiSpeak is a virtual workspace with avatar movement and real-time voice communication.

## Frontend Demonstration
1. Launch the React and Vite frontend.
2. Connect to the Socket.IO backend.
3. Demonstrate the 3D workspace and avatar movement.
4. Enable microphone permissions.
5. Connect two browser sessions.

## Audio Features
- Real-time WebRTC voice communication.
- Studio proximity-based audio.
- Same-room communication.
- Different-room audio isolation.
- Microphone mute and unmute.

## Verified Locally
- Real-time voice communication.
- Room-based audio isolation.
- Microphone mute.
- Studio proximity behavior.

## Pending Verification
